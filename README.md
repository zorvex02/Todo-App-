# To-Do App

A simple and responsive task management app built with **HTML, CSS, and JavaScript**. It allows users to create, manage, and track tasks while keeping their data saved in the browser.

## Features

*  Add new tasks
*  Mark tasks as completed
*  Undo completed tasks
*  Edit existing tasks
*  Delete tasks
*  Track pending, completed, and total tasks
*  Persistent data using LocalStorage
*  Responsive design for different screen sizes

## Built With

* **HTML5** — Website structure
* **CSS3** — Styling and responsive design
* **JavaScript** — Application logic and interactivity
* **LocalStorage** — Saving tasks in the browser
