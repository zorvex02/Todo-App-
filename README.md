# To-Do App

A simple and responsive To-Do App built with **HTML, CSS, and JavaScript**.

## Features

* Add tasks
* Mark tasks as completed
* Undo completed tasks
* Edit tasks
* Delete tasks
* Pending, completed, and total task counters
* LocalStorage persistence
* Responsive design

## Built With

* HTML5
* CSS3
* JavaScript
